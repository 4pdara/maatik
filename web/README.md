# העורך של מעתיק (אב-טיפוס)

אתר שרץ אצלך במחשב ומדבר עם המנוע ב-Modal. הסריקות והתעתוק נשמרים במנוע, לא במחשב.

## הפעלה בפעם הראשונה
1. התקן Node.js בגרסה 20 ומעלה (nodejs.org).
2. בתיקייה `web`:
   ```
   npm install
   ```
3. העתק את `.env.example` לקובץ חדש בשם `.env.local` (באותה תיקייה), ומלא את `MODAL_TOKEN_SECRET`:
   זה ה-Token Secret של Modal (באתר Modal: Settings, API Tokens). הקובץ לא נכנס ל-git.

## הפעלה
```
npm run dev
```
ואז לפתוח בדפדפן: http://localhost:3000

## מה יש
- **כתבי היד** (המסך הראשון) ← **העמודים** של כתב יד, עם מצב לכל עמוד ← **העורך**.
- **העורך, צד מול צד:** הסריקה מימין והשורות משמאל. לחיצה על שורה בכל צד מסמנת אותה בשניהם.
- **שורה מעל שורה:** כל שורה חתוכה מהסריקה והתעתוק מתחתיה. המעבר בכפתור למעלה.
- **מקלדת:** Enter מאשר ועובר לשורה הבאה. Alt עם חץ למעלה או למטה עובר בין שורות. Alt+2 משאיר קריאה מסופקת. Ctrl+Z (מחוץ לשדה) מבטל.
- **חסרה כאן שורה:** לוחצים בסריקה על תחילת השורה ועל סופה, ומקלידים.
- **שמירה אוטומטית** אחרי כל שינוי. אם השמירה נכשלה, השינויים נשמרים בדפדפן ומופיעה הודעה.
- **שפר את המודל:** מראה כמה שורות חדשות אושרו, מתחיל אימון ב-Modal ומראה את ההתקדמות. גרסה חדשה מחליפה את הקודמת רק אם היא טועה פחות בעמודי הבדיקה.

## איך זה בנוי
- `src/app/api/engine/[...path]/route.ts`: מעביר בקשות מהדפדפן למנוע ומוסיף את האסימון. האסימון לא מגיע לדפדפן.
- `src/styles/tokens.css`: הצבעים והגופנים מ-docs/DESIGN.md. הגופנים מוטמעים מחבילות fontsource.
- `src/components/Editor.tsx`: העורך. `ScanView.tsx` הסריקה, `LineCards.tsx` מצב שורה מעל שורה, `TrainingDialog.tsx` האימון.
