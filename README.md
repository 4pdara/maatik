# מעתיק (maatik)

מערכת שמקבלת סריקות של כתבי יד של אחרונים (1700 ואילך), מזהה את השורות ואת הטקסט, לומדת את הכתב של כל כתב יד מהשורות שמגיהים בה, ומחזירה תעתוק מוכן להגהה.

**השלב: אב-טיפוס.** רק אוריאל משתמש. מה בונים ולמה: [docs/SPEC.md](docs/SPEC.md). מה נעשה ומה נבדק: [STATUS.md](STATUS.md). הכללים לעבודה: [CLAUDE.md](CLAUDE.md).

## איפה זה רץ

| מה | כתובת | גישה |
|---|---|---|
| **האתר** (העורך) | https://pdara--maatik-web.us-east.modal.run | סיסמת כניסה |
| **התוכנה למחשב** | [הורדה מדף ה-Releases](https://github.com/4pdara/maatik/releases/tag/desktop-v0.1.0) | אותה סיסמה (התוכנה פותחת את האתר בחלון משלה) |
| המנוע (API) | https://pdara--maatik-engine-api.us-east.modal.run | אסימון בלבד, לא לדפדפן |

הכול רץ בחשבון Modal של אוריאל (אזור us-east), בתוך הקרדיט החינמי. הסריקות, התעתוק והמודלים נמצאים ב-Modal Volume בשם `maatik-data`, ולא ב-git.

## העבודה, בקצרה
1. מעלים סריקות של כתב יד. היום זה נעשה בסקריפט `engine/scripts/engine_client.py upload`.
2. המנוע מזהה כל עמוד: שורות, טקסט, ומילים שהוא לא בטוח בהן.
3. בעורך מגיהים: הסריקה מימין והשורות משמאל, מתקנים ומאשרים שורה אחרי שורה.
4. "שפר את המודל" מאמן גרסה חדשה של המודל של אותו כתב יד מהשורות שאושרו. היא מחליפה את הקודמת רק אם היא טועה פחות בעמודי הבדיקה, ואז העמודים שעוד לא הוגהו מזוהים מחדש.

**תוצאה עד עכשיו** (כתב יד טולידאנו, 104 שורות בעמודי הבדיקה): שגיאות באותיות ירדו מ-5.68% ל-3.23% אחרי כיול אחד.

## מבנה המאגר

| תיקייה | מה יש בה |
|---|---|
| `engine/` | המנוע: חבילת Python עם Kraken (זיהוי ואימון), והמעטפת ל-Modal (`modal_app.py`) עם ה-API. בדיקות ב-`engine/tests`. |
| `web/` | האתר והעורך: Next.js 15. רץ ב-Modal (`web/modal_web.py`) או מקומית. הוראות: [web/README.md](web/README.md). |
| `desktop/` | התוכנה למחשב: Tauri 2. חלון שפותח את האתר. |
| `docs/` | אפיון, עיצוב וסיכונים. |
| `.github/workflows/` | פריסה אוטומטית (פירוט בהמשך). |

## פריסה (אוטומטית)
כל דחיפה ל-GitHub שמשנה קבצים באחת מהתיקיות מפעילה את הפריסה שלה:

| שינוי ב- | מה קורה | Workflow |
|---|---|---|
| `engine/` | המנוע נפרס מחדש ל-Modal | `deploy-engine.yml` |
| `web/` | האתר נפרס מחדש ל-Modal | `deploy-web.yml` |
| `desktop/` | התוכנה נבנית ל-Windows ול-Mac ומתעדכנת בדף ה-Releases | `build-desktop.yml` |

כתובת האתר והמנוע אחרי כל פריסה מופיעה גם כסטטוס על ה-commit ב-GitHub.

**הערה:** GitHub מריץ Actions במאגר פרטי רק כשהחיוב בחשבון מסודר. אם המאגר פרטי והחיוב חסום, הפריסות לא ירוצו.

## סודות (Settings ← Secrets and variables ← Actions)

| שם | למה |
|---|---|
| `MODAL_TOKEN_ID`, `MODAL_TOKEN_SECRET` | הפריסה ל-Modal. אסימון ה-API של המנוע נגזר מהם. |
| `MAATIK_WEB_PASSWORD` | סיסמת הכניסה לאתר, לפחות 10 תווים. |

- **בלי `MAATIK_WEB_PASSWORD`** האתר נפרס נעול, עם סיסמה אקראית שאף אחד לא יודע.
- **החלפת סיסמה:** מעדכנים את הסוד ומריצים מחדש את deploy-web (Actions ← deploy-web ← Run workflow). כל מי שמחובר יתנתק.
- **סודות לא נכנסים** לקוד, ללוגים או למאגר.

## התקנת התוכנה למחשב
- **Windows:** מורידים את `Maatik_..._x64-setup.exe` מדף ה-Releases ומריצים. לא צריך הרשאות מנהל.
  התוכנה עוד לא חתומה דיגיטלית, ולכן Windows יציג "Windows protected your PC". לוחצים "More info" ואז "Run anyway".
- **Mac** (מעבד Apple): מורידים את קובץ ה-`.dmg` וגוררים ל-Applications.
  בפתיחה הראשונה לוחצים על התוכנה עם הכפתור הימני ובוחרים "Open", כי היא עוד לא חתומה.
- **מה צריך:** חיבור לאינטרנט. כל העבודה נשמרת במנוע, לא במחשב.

## הרצה מקומית (למפתחים)
- **האתר:** `cd web && npm install && npm run dev`, עם `web/.env.local` לפי `web/.env.example`. מקומית אין סיסמה.
- **בדיקות המנוע:** `cd engine && pip install -e ".[dev,align]" && pytest`. Kraken רץ רק על Linux ו-Mac.
- **לקוח שורת פקודה למנוע:** `python engine/scripts/engine_client.py --help` (צריך `MAATIK_ENGINE_URL` ו-`MODAL_TOKEN_SECRET`).

## עלויות
- **אימון של כתב יד** (8 ליבות): בערך 0.70 דולר להרצה.
- **זיהוי עמוד:** פחות מסנט.
- **האתר:** בערך 3 סנט לשעה כשמשתמשים בו. אחרי 5 דקות בלי שימוש הוא נכבה, ואז לא עולה כלום.
- **רישום:** כל הרצה נרשמת ב-`runs.jsonl` עם משך ועלות משוערת.
